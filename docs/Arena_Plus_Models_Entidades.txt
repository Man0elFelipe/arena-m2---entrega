ARENA+ - DEFINIÇÃO INICIAL DAS MODELS/ENTIDADES
Projeto Interdisciplinar
Integrante: Gustavo Heli L, Guilherme Macario, Alexandre Henrique, Juan Rocha<, Manoel Felipe

O Arena+ é uma rede social voltada ao esporte. Esta definição inicial
considera cadastro de usuários, publicações, comentários, curtidas,
seguimento de pessoas e participação em comunidades esportivas.
Os tipos abaixo seguem a nomenclatura Java. As entidades ainda podem
ser ajustadas durante o desenvolvimento do projeto.

1. USUARIO
Representa uma pessoa cadastrada na plataforma.

Atributo             Tipo Java          Descrição
id                   Long               Identificador do usuário
nome                 String             Nome do usuário
email                String             Email usado no login
senhaHash            String             Hash da senha, sem guardar a senha original
fotoPerfilUrl        String             Caminho ou endereço da foto de perfil
biografia            String             Apresentação do usuário
cidade               String             Cidade do usuário
esportePrincipal     String             Esporte de maior interesse
tipoPerfil           String             COMUM ou ADMINISTRADOR
ativo                Boolean            Indica se a conta está ativa
dataCadastro         LocalDateTime      Data e hora do cadastro

2. PUBLICACAO
Representa um conteúdo publicado no feed ou em uma comunidade.

Atributo             Tipo Java          Descrição
id                   Long               Identificador da publicação
usuarioId            Long               Usuário autor da publicação
comunidadeId         Long               Comunidade da publicação (opcional)
texto                String             Texto da publicação
midiaUrl             String             Caminho ou endereço da mídia (opcional)
tipoMidia            String             IMAGEM ou VIDEO (opcional)
dataPublicacao       LocalDateTime      Data e hora da publicação
dataEdicao           LocalDateTime      Data e hora da última edição (opcional)

3. COMENTARIO
Representa um comentário feito em uma publicação.

Atributo             Tipo Java          Descrição
id                   Long               Identificador do comentário
usuarioId            Long               Usuário que comentou
publicacaoId         Long               Publicação que recebeu o comentário
texto                String             Conteúdo do comentário
dataComentario       LocalDateTime      Data e hora do comentário

4. CURTIDA
Registra a curtida de um usuário em uma publicação.

Atributo             Tipo Java          Descrição
id                   Long               Identificador da curtida
usuarioId            Long               Usuário que curtiu
publicacaoId         Long               Publicação curtida
dataCurtida          LocalDateTime      Data e hora da curtida

5. SEGUIMENTO
Registra quando um usuário segue outro usuário.

Atributo             Tipo Java          Descrição
id                   Long               Identificador do seguimento
seguidorId           Long               Usuário que começou a seguir
seguidoId            Long               Usuário que está sendo seguido
dataSeguimento       LocalDateTime      Data e hora do início do seguimento

6. COMUNIDADE
Representa um grupo voltado a um esporte ou tema esportivo.

Atributo             Tipo Java          Descrição
id                   Long               Identificador da comunidade
nome                 String             Nome da comunidade
descricao            String             Apresentação e objetivo do grupo
esporte              String             Esporte relacionado à comunidade
imagemUrl            String             Caminho ou endereço da imagem do grupo
criadorId            Long               Usuário que criou a comunidade
dataCriacao          LocalDateTime      Data e hora da criação

7. MEMBROCOMUNIDADE
Registra a participação de um usuário em uma comunidade.

Atributo             Tipo Java          Descrição
id                   Long               Identificador da participação
usuarioId            Long               Usuário participante
comunidadeId         Long               Comunidade da qual participa
papel                String             MEMBRO ou MODERADOR
dataEntrada          LocalDateTime      Data e hora de entrada na comunidade

OBSERVAÇÕES

- Long representa identificadores; String representa textos;
  Boolean representa verdadeiro ou falso; LocalDateTime representa
  data e hora e pertence ao pacote java.time.
- Atributos que identificam outra entidade representam relacionamentos.
  Por exemplo, usuarioId em Publicacao aponta para Usuario.
- O administrador é identificado pelo tipoPerfil de Usuario.
- Um usuário pode criar várias publicações e comentários, seguir várias
  pessoas e participar de várias comunidades.
- Cada publicação tem um autor e pode pertencer a uma comunidade.
- Cada comentário e curtida pertencem a uma publicação e a um usuário.
- Cada usuário pode curtir uma mesma publicação apenas uma vez.
- Não deve haver seguimentos repetidos nem um usuário seguir a si mesmo.
- Cada usuário pode ter apenas um vínculo de participação por comunidade.
- A proposta inicial considera até uma imagem ou um vídeo por publicação.
- Foto, biografia, cidade, esporte principal e imagem da comunidade podem
  ficar sem preenchimento. Os campos marcados como opcionais também
  podem ficar sem valor. Os demais são previstos como obrigatórios.
- O histórico do Arena Coach poderá receber entidades próprias em uma
  próxima etapa, caso seja incluído no escopo do semestre.
